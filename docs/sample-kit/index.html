# Follow-Up Agent kit for Harbor Plumbing & Drain (a sample business)

Nothing you quoted goes quiet. You sent the quote on Tuesday. Nobody rejected it. It just got buried. This chases every estimate until the customer actually answers.

This is an **Operator-sized** agent with 5 capabilities, generated by BlvkWare from the answers you gave.

## What this kit is, and is not

It is the complete specification and configuration of one agent: its instructions, the tools it may use and what each one is allowed to do, the order it does things in, the records it keeps, the rules that stop it acting beyond its authority, and the tests that say whether it works.

It is **not** running software. It does not connect to your systems by itself and contains no credentials. You, or whoever builds for you, load it into the agent framework or automation tool you already use. Every file is plain JSON or Markdown and works with any of them.

## Start here

1. **SETUP.md**: the facts only you can supply (working hours, prices, the real people behind each route). The agent must not run until these are filled in.
2. **prompts/system.md**: the agent's instructions. `prompts/system-full.md` adds every capability's procedure, for frameworks without per-task instructions.
3. **tools/**: the same tools in four formats. Implement each tool as a call to your own system.
4. **policies/autonomy.json**: what the agent may do on its own. Every tool has an effect (read, internal, external); each level allows some effects and holds the rest for a person. The kit starts at **L1 Draft**. A prompt is advice; the runtime below makes it a rule.
5. **runtime/**: the rules above, already in code. Put `runtime/blvk_runtime.py` between your model and your systems and every tool call is checked: the autonomy level, approvals, the audit log, opt-outs, quiet hours and the money limit. Prove it with `python -m unittest runtime/test_runtime.py -v`. See `runtime/README.md`.
6. **tests/**: `scenarios.md` walks each capability through its own test; `acceptance.md` says when it passes. Run them before trusting it with a real customer.

## Loading it

- **OpenAI** (Responses or Chat Completions): system prompt from `prompts/system.md`, `tools/openai.json` as the tools. The full loop, with the runtime in it, is `runtime/example_openai.py`.
- **Anthropic** (Messages API): system prompt from `prompts/system.md`, `tools/anthropic.json` as the tools. The full loop is `runtime/example_anthropic.py`.
- **MCP**: `tools/mcp.json` lists every tool with MCP annotations (read-only tools are marked `readOnlyHint`, external ones `openWorldHint`). Implement them in an MCP server and connect any MCP client.
- **n8n, Make, Zapier and similar**: each `workflows/<capability>.json` is one scenario: its trigger, its steps in order, and which steps must wait for approval. Use the system prompt in the AI step.

# Before you switch it on

The kit contains behaviour, not facts about your business. Everything below is a fact only you can supply. Fill each one into the setting it names (in `workflows/`) before the agent runs.

## Settings to fill in

- **Booking** `durations`: how long each kind of job takes.
- **Booking** `buffer_minutes`: travel or preparation time between bookings.
- **Booking** `working_hours`: when bookings are allowed.
- **SMS** `business_number`: the business number the agent uses.
- **Interaction logging** `field_mapping`: which CRM field each value belongs in.
- **CRM read and write** `field_mapping`: which CRM field each value belongs in.

## What each capability needs from you

- **Booking**: job durations, travel buffers and working hours.
- **SMS**: A2P 10DLC registration, which takes weeks and is outside anyone's control.
- **CRM read and write**: field mapping to your CRM.

## Runtime settings

- **Time zone** (`runtime/config.json` `business_timezone`): your IANA time zone, so quiet hours are yours.
- **Money limit at L2** (`policies/autonomy.json` `limits_at_L2`): the largest refund or payment the agent may make without asking. Until it is set, every one is held.
- **A handler for each tool** you use: a short function that makes the call to your system. See `runtime/README.md`.
- **Optional: Laya** (`pip install laya`) for the local checks on messages and drafts. The rules layer runs without it.

## Access to your systems

- **Email**: see `integrations/email.md`.
- **CRM**: see `integrations/crm.md`.
- **Calendar / scheduling**: see `integrations/calendar.md`.
- **Field service / jobs**: see `integrations/fsm.md`.
- **Phone system**: see `integrations/telephony.md`.

## Outside anyone's control

- Texting your customers from a US business number requires A2P 10DLC registration with the carriers. Part of it is a manual review that nobody can hurry, so budget weeks rather than days. Build and test everything else meanwhile, and switch SMS on when the registration clears.

# The runtime: your agent's rules, enforced in code

A prompt is advice. This folder is the part that makes the rules hold even when
the model gets it wrong. Put it between your model and your systems and every
tool call is checked before anything happens.

| File | What it does |
| --- | --- |
| `blvk_runtime.py` | The gate. Checks each call against your autonomy level, holds actions for approval, keeps the audit log, honours opt-outs, quiet hours and the money limit. Also the approvals command line. |
| `guards.py` | Checks each customer message for injected instructions, opt-outs and requests for a person, and each draft for prices, dates and your own "never do" rules. |
| `test_runtime.py` | Tests that prove the rules hold for this kit's tools. Run them before you trust it. |
| `example_anthropic.py`, `example_openai.py` | The full loop with each provider, about 50 lines each. |
| `config.json` | Your time zone, quiet hours and guard thresholds. |

Plain Python 3.9+, standard library only. No account, no server, no keys in any file.

## Five minutes to a working gate

```
python -m unittest runtime/test_runtime.py -v     # every rule, tested against this kit
python runtime/blvk_runtime.py status
```

Then, in your own code:

```python
from blvk_runtime import Runtime

rt = Runtime()                                   # reads this kit's policy files

@rt.handler("crm_get")                           # one handler per tool: a call to your system
def crm_get(args):
    return my_crm.get(args["record_id"])

result = rt.call(tool_name, tool_input)          # what your loop does for every tool call
result.status    # done | held | deferred | refused | failed
result.for_model()                               # the tool result to give back to the model
```

Every minute or so, call `rt.run_due()`: it carries out actions a person has
approved and sends that were waiting for quiet hours to end.

## What happens to each kind of call

| Effect | L0 Watch | L1 Draft | L2 Approve | L3 Operate |
| --- | --- | --- | --- | --- |
| read | runs | runs | runs | runs |
| internal (your own records) | refused | runs | runs | runs |
| external (customers, suppliers, money) | refused | held for a person | runs below the money limit, else held | runs |

On top of that, at every level: a contact who opted out is never contacted, a
customer-facing send at night waits until morning, and a draft the outbound
check flags is held for a person even at L3.

```
python runtime/blvk_runtime.py reject appr_1a2b3c --by Sam --note "wrong price"

```

`suppressed.json`, `escalations.jsonl`, `scheduled.json`. Plain JSON, readable
by a person and by anything you build on top (a Slack button, a small web page).

Every tool call your agent makes goes through Runtime.call(). It enforces this
kit's own policy files, so the rules hold in code and not only in the prompt:

  * the autonomy level (policies/autonomy.json): each tool's effect (read,
    internal, external) is checked against the level before anything runs;
  * held actions become real approval records a person decides on;
  * an append-only, hash-chained audit log, written BEFORE each action;
  * opt-outs: nobody on the suppression list is contacted, at any level;
  * quiet hours: nothing reaches a customer at night; it waits instead;
  * the L2 money limit: refunds above it are held;
  * guards (guards.py): inbound messages are checked for injected instructions,
    opt-outs and requests for a person; outbound drafts are checked for prices,
    dates and your own "never do" rules, and held when they trip.

Standard library only (Python 3.9+). It stores its state as JSON files in a
folder, so it runs anywhere and every decision can be read by a person.

    from blvk_runtime import Runtime
    rt = Runtime()                      # finds the kit from this file's location
    @rt.handler("crm_get")              # one handler per tool: a call to YOUR system
    def crm_get(args): ...
    result = rt.call("email_send", {"to": ["a@b.com"], "subject": "Hi", "body": "..."})
    result.status                       # done | held | deferred | refused | failed

Command line (for the person who approves things):

    python blvk_runtime.py approvals            list what is waiting
    python blvk_runtime.py approve <id> --by Sam
    python blvk_runtime.py reject <id> --by Sam --note "wrong customer"
    python blvk_runtime.py suppress <contact> --reason "asked by phone"
    python blvk_runtime.py verify-log           check nobody edited the log
    python blvk_runtime.py status

Approvals decided on the command line are carried out by your agent process on
its next Runtime.run_due() call, with your handlers, at an allowed hour.
"""

# Tools whose input names the people they reach, and where.
CONTACT_FIELDS = {
    "email_send": "to",
    "telephony_send_sms": "to",
    "telephony_call": "to",
    "calendar_create_event": "attendees",
}
# Tools that move money, and the field that says how much.
MONEY_FIELDS = {"payments_refund": "amount", "ecom_refund": "amount"}
# Tools whose text a customer will read: checked by the outbound guard.
OUTBOUND_TEXT = {
    "email_send": "body",
    "email_draft": "body",
    "telephony_send_sms": "body",
    "helpdesk_reply": "body",
    "calendar_create_event": "notes",
}
# Customer-facing tools that must respect quiet hours.
QUIET_TOOLS = {"email_send", "telephony_send_sms", "telephony_call", "helpdesk_reply",
               "calendar_create_event", "calendar_update_event", "accounting_send_invoice"}

BUILTINS = ("agent_log", "agent_request_approval", "agent_escalate", "agent_schedule",
            "agent_is_suppressed", "agent_suppress")

GENESIS = "0" * 64


def utcnow() -> dt.datetime:
    return dt.datetime.now(dt.timezone.utc)


def iso(t: dt.datetime) -> str:
    return t.astimezone(dt.timezone.utc).isoformat(timespec="seconds").replace("+00:00", "Z")


def parse_iso(s: str) -> dt.datetime:
    return dt.datetime.fromisoformat(s.replace("Z", "+00:00"))


def zone(name: Optional[str]):
    """A tzinfo for an IANA name, or UTC when the name is empty or unknown.

    On Windows, IANA zones need the `tzdata` package (pip install tzdata)."""
    if not name:
        return dt.timezone.utc
    try:
        from zoneinfo import ZoneInfo
        return ZoneInfo(name)
    except Exception:
        return dt.timezone.utc


def norm_contact(value: str) -> str:
    v = str(value).strip().lower()
    if "@" in v:
        return v
    digits = re.sub(r"[^\d+]", "", v)
    return digits or v


def unset(value: Any) -> bool:
    return value is None or (isinstance(value, dict) and "set_this" in value)


@dataclass
class Result:
    status: str                       # done | held | deferred | refused | failed
    tool: str
    output: Any = None
    reason: str = ""
    approval_id: Optional[str] = None
    retry_at: Optional[str] = None
    flags: list = field(default_factory=list)

    @property
    def ok(self) -> bool:
        return self.status == "done"

    def as_dict(self) -> dict:
        d = asdict(self)
        return {k: v for k, v in d.items() if v not in (None, "", [])}

    def for_model(self) -> str:
        """What to hand back to the model as the tool result."""
        if self.status == "done":
            return json.dumps({"status": "done", "output": self.output}, default=str)
        explain = {
            "held": "Held for a person to approve. It has NOT happened yet. Tell the person it is waiting for approval.",
            "deferred": f"Not sent: it is quiet hours for the recipient. It will go at {self.retry_at}.",
            "refused": "Refused by the runtime. Do not try to work around this; tell the person or escalate.",
            "failed": "The system call failed. Do not assume it happened.",
        }[self.status]
        return json.dumps({"status": self.status, "reason": self.reason, "note": explain,
                           "approval_id": self.approval_id, "flags": self.flags or None}, default=str)


class RuntimeError_(Exception):
    pass


class Store:
    """JSON files in one folder. Atomic writes; one lock per process."""

    def __init__(self, root: Path):
        self.root = Path(root)
        (self.root / "approvals").mkdir(parents=True, exist_ok=True)
        self.lock = threading.RLock()

    def path(self, name: str) -> Path:
        return self.root / name

    def read_json(self, name: str, default: Any) -> Any:
        p = self.path(name)
        if not p.exists():
            return default
        return json.loads(p.read_text(encoding="utf-8"))

    def write_json(self, name: str, value: Any) -> None:
        p = self.path(name)
        tmp = p.with_suffix(p.suffix + f".{os.getpid()}.tmp")
        tmp.write_text(json.dumps(value, indent=2, ensure_ascii=False, default=str) + "\n", encoding="utf-8")
        os.replace(tmp, p)

    def append_line(self, name: str, value: dict) -> None:
        with open(self.path(name), "a", encoding="utf-8") as f:
            f.write(json.dumps(value, ensure_ascii=False, default=str, sort_keys=True) + "\n")
            f.flush()
            os.fsync(f.fileno())

    def lines(self, name: str) -> list:
        p = self.path(name)
        if not p.exists():
            return []
        return [json.loads(line) for line in p.read_text(encoding="utf-8").splitlines() if line.strip()]


class Runtime:
    def __init__(self, kit: Path | str = KIT, state: Path | str | None = None, level: Optional[str] = None,
                 now: Optional[Callable[[], dt.datetime]] = None, guard: Any = "auto"):
        self.kit = Path(kit)
        cfg = self._json("runtime/config.json", {})
        policy = self._json("policies/autonomy.json", {})
        catalog = self._json("tools/tools.json", {"tools": []})
        self.manifest = self._json("agent.json", {})
        self.tools = {t["name"]: t for t in catalog["tools"]}
        self.level = os.environ.get("BLVK_LEVEL") or level or policy.get("level", "L1")
        if self.level not in ("L0", "L1", "L2", "L3"):
            raise RuntimeError_(f"unknown autonomy level {self.level!r}")
        self.config = cfg
        self.business_tz = os.environ.get("BLVK_TIMEZONE") or (None if unset(cfg.get("business_timezone")) else cfg.get("business_timezone"))
        quiet = cfg.get("quiet_hours") or {"from": "21:00", "to": "08:00"}
        self.quiet_from, self.quiet_to = quiet.get("from", "21:00"), quiet.get("to", "08:00")
        limit = (policy.get("limits_at_L2") or {}).get("money", {})
        limit = limit.get("value") if isinstance(limit, dict) else limit
        env_limit = os.environ.get("BLVK_MONEY_LIMIT")
        self.money_limit = float(env_limit) if env_limit else (float(limit) if isinstance(limit, (int, float)) else None)
        self.now = now or utcnow
        self.store = Store(Path(state) if state else Path(os.environ.get("BLVK_STATE", self.kit / "state")))
        self.handlers: dict[str, Callable[[dict], Any]] = {}
        self.warnings: list[str] = []
        if not self.business_tz:
            self.warnings.append("business_timezone is not set in runtime/config.json: quiet hours use UTC until it is.")
        elif zone(self.business_tz) is dt.timezone.utc and self.business_tz.upper() not in ("UTC", "ETC/UTC", "Z"):
            self.warnings.append(f"time zone {self.business_tz!r} is not known here (on Windows: pip install tzdata); quiet hours use UTC.")
        if guard == "auto":
            try:
                from guards import Guard  # same folder
                guard = Guard(self.kit / "guards" / "checks.json")
            except Exception as exc:  # the runtime still enforces policy without guards
                self.warnings.append(f"guards unavailable ({exc}); inbound and outbound checks are off.")
                guard = None
        self.guard = guard

    # ---- setup ---------------------------------------------------------------

    def _json(self, rel: str, default: Any) -> Any:
        p = self.kit / rel
        return json.loads(p.read_text(encoding="utf-8")) if p.exists() else default

    def handler(self, name: str):
        """Decorator: register the function that performs a tool against your system."""
        def wrap(fn):
            self.register(name, fn)
            return fn
        return wrap

    def register(self, name: str, fn: Callable[[dict], Any]) -> None:
        if name not in self.tools:
            raise RuntimeError_(f"{name} is not a tool in this kit")
        if name in BUILTINS:
            raise RuntimeError_(f"{name} is provided by the runtime itself")
        self.handlers[name] = fn

    # ---- the audit log -------------------------------------------------------

    def log(self, event: str, outcome: str, *, detail: Optional[dict] = None, capability: Optional[str] = None,
            record_ref: Optional[str] = None, source: str = "rules") -> dict:
        with self.store.lock:
            entries = self.store.lines("audit.jsonl")
            prev = entries[-1]["hash"] if entries else GENESIS
            entry = {"id": uuid.uuid4().hex, "at": iso(self.now()), "event": event, "outcome": outcome,
                     "autonomy_level": self.level, "source": source, "prev": prev}
            if capability:
                entry["capability"] = capability
            if record_ref:
                entry["record_ref"] = record_ref
            if detail:
                entry["detail"] = detail
            entry["hash"] = self._hash(entry)
            self.store.append_line("audit.jsonl", entry)
            return entry

    @staticmethod
    def _hash(entry: dict) -> str:
        body = {k: v for k, v in entry.items() if k != "hash"}
        return hashlib.sha256(json.dumps(body, sort_keys=True, ensure_ascii=False, default=str).encode()).hexdigest()

    def verify_log(self) -> tuple[bool, str]:
        prev = GENESIS
        for n, entry in enumerate(self.store.lines("audit.jsonl"), 1):
            if entry.get("prev") != prev:
                return False, f"entry {n} does not follow entry {n - 1}: an entry was removed or reordered"
            if self._hash(entry) != entry.get("hash"):
                return False, f"entry {n} was edited after it was written"
            prev = entry["hash"]
        return True, "intact"

    # ---- suppression, quiet hours, money ----------------------------------------

    def suppressed(self) -> dict:
        return self.store.read_json("suppressed.json", {})

    def is_suppressed(self, contact: str) -> bool:
        return norm_contact(contact) in self.suppressed()

    def suppress(self, contact: str, reason: str, by: str = "agent") -> None:
        with self.store.lock:
            s = self.suppressed()
            s[norm_contact(contact)] = {"reason": reason, "by": by, "at": iso(self.now())}
            self.store.write_json("suppressed.json", s)

    def recipients(self, name: str, args: dict) -> list[str]:
        f = CONTACT_FIELDS.get(name)
        if not f or f not in args:
            return []
        v = args[f]
        return [str(x) for x in (v if isinstance(v, list) else [v])]

    def quiet_until(self, tz_name: Optional[str] = None) -> Optional[dt.datetime]:
        """None when sending is allowed now; otherwise when the quiet period ends."""
        tz = zone(tz_name or self.business_tz)
        local = self.now().astimezone(tz)
        fh, fm = map(int, self.quiet_from.split(":"))
        th, tm = map(int, self.quiet_to.split(":"))
        start, end = local.replace(hour=fh, minute=fm, second=0, microsecond=0), local.replace(hour=th, minute=tm, second=0, microsecond=0)
        if start > end:  # crosses midnight, e.g. 21:00 to 08:00
            if local >= start:
                return end + dt.timedelta(days=1)
            if local < end:
                return end
            return None
        return end if start <= local < end else None

    # ---- the gate --------------------------------------------------------------

    def decide(self, name: str, args: dict) -> tuple[str, str]:
        """(allow | hold | refuse, reason) from the effect and the level alone."""
        effect = self.tools[name]["effect"]
        if effect == "read":
            return "allow", "read"
        if self.level == "L0":
            return "refuse", f"{effect} tools are not allowed at L0 Watch"
        if effect == "internal":
            return "allow", "internal"
        if self.level == "L1":
            return "hold", "external actions are held for a person at L1 Draft"
        if self.level == "L2" and name in MONEY_FIELDS:
            amount = args.get(MONEY_FIELDS[name])
            if self.money_limit is None:
                return "hold", "no money limit is set for L2, so every payment is held"
            if not isinstance(amount, (int, float)) or amount > self.money_limit:
                return "hold", f"amount {amount} is above the L2 limit of {self.money_limit}"
        return "allow", f"external, allowed at {self.level}"

    def validate(self, name: str, args: Any) -> Optional[str]:
        if not isinstance(args, dict):
            return "input must be an object"
        schema = self.tools[name].get("input_schema") or {}
        props = schema.get("properties", {})
        for req in schema.get("required", []):
            if req not in args:
                return f"missing required field {req!r}"
        if schema.get("additionalProperties") is False:
            extra = [k for k in args if k not in props]
            if extra:
                return f"unknown field(s) {extra}"
        types = {"string": str, "number": (int, float), "integer": int, "boolean": bool, "array": list, "object": dict}
        for k, v in args.items():
            spec = props.get(k, {})
            t = types.get(spec.get("type"))
            if t and not isinstance(v, t) or (spec.get("type") in ("number", "integer") and isinstance(v, bool)):
                return f"{k!r} must be {spec.get('type')}"
            if "enum" in spec and v not in spec["enum"]:
                return f"{k!r} must be one of {spec['enum']}"
        return None

    def call(self, name: str, args: Optional[dict] = None, *, capability: Optional[str] = None,
             record_ref: Optional[str] = None, why: Optional[str] = None, recipient_tz: Optional[str] = None) -> Result:
        args = dict(args or {})
        if name not in self.tools:
            self.log(f"refused unknown tool {name}", "refused", capability=capability)
            return Result("refused", name, reason=f"{name} is not a tool in this kit")
        problem = self.validate(name, args)
        if problem:
            self.log(f"refused {name}: {problem}", "refused", capability=capability, record_ref=record_ref)
            return Result("refused", name, reason=problem)
        if name in BUILTINS:
            return self._builtin(name, args, capability)

        decision, reason = self.decide(name, args)
        flags: list = []
        for contact in self.recipients(name, args):
            if self.is_suppressed(contact):
                self.log(f"refused {name}: {contact} has opted out", "refused", capability=capability,
                         record_ref=record_ref, detail={"tool": name})
                return Result("refused", name, reason=f"{contact} has opted out and must not be contacted")
        if decision == "refuse":
            self.log(f"refused {name}: {reason}", "refused", capability=capability, record_ref=record_ref)
            return Result("refused", name, reason=reason)

        text = args.get(OUTBOUND_TEXT.get(name, ""), "")
        if self.guard and isinstance(text, str) and text.strip() and self.tools[name]["effect"] != "read":
            verdict = self.guard.check_outbound(text)
            flags = verdict.get("reasons", [])
            if verdict.get("flagged") and self.tools[name]["effect"] == "external" and decision == "allow":
                decision, reason = "hold", "the outbound check flagged this message: " + "; ".join(flags)

        if decision == "hold":
            appr = self._hold(name, args, why or reason, capability, record_ref, flags)
            return Result("held", name, reason=reason, approval_id=appr["id"], flags=flags)

        if name in QUIET_TOOLS:
            wait = self.quiet_until(recipient_tz)
            if wait:
                task = self._schedule_call(name, args, wait, capability, record_ref)
                self.log(f"deferred {name} until {iso(wait)} (quiet hours)", "held", capability=capability,
                         record_ref=record_ref, detail={"tool": name, "task": task["id"]})
                return Result("deferred", name, reason="quiet hours", retry_at=iso(wait), flags=flags)
        return self._run(name, args, capability, record_ref, source="model", flags=flags)

    def _run(self, name: str, args: dict, capability, record_ref, source: str, flags=None) -> Result:
        fn = self.handlers.get(name)
        if not fn:
            self.log(f"failed {name}: no handler registered", "failed", capability=capability, record_ref=record_ref)
            return Result("failed", name, reason=f"no handler is registered for {name}")
        # Written before the action it records, as the audit schema requires.
        self.log(f"call {name}", "done", capability=capability, record_ref=record_ref, source=source,
                 detail={"tool": name, "input": args})
        try:
            out = fn(args)
        except Exception as exc:
            self.log(f"failed {name}: {type(exc).__name__}: {exc}", "failed", capability=capability, record_ref=record_ref)
            return Result("failed", name, reason=f"{type(exc).__name__}: {exc}", flags=flags or [])
        return Result("done", name, output=out, flags=flags or [])

    # ---- approvals ---------------------------------------------------------------

    def _hold(self, name, args, why, capability, record_ref, flags) -> dict:
        appr = {"id": "appr_" + uuid.uuid4().hex[:12], "action": name, "input": args, "why": why,
                "requested_at": iso(self.now()), "decision": "pending"}
        if record_ref:
            appr["record_ref"] = record_ref
        if capability:
            appr["capability"] = capability
        if flags:
            appr["flags"] = flags
        self.log(f"held {name} for approval", "held", capability=capability, record_ref=record_ref,
                 detail={"approval": appr["id"], "why": why, "flags": flags or None})
        self.store.write_json(f"approvals/{appr['id']}.json", appr)
        return appr

    def approvals(self, pending_only: bool = True) -> list[dict]:
        out = []
        for p in sorted((self.store.root / "approvals").glob("appr_*.json")):
            a = json.loads(p.read_text(encoding="utf-8"))
            if not pending_only or a["decision"] == "pending":
                out.append(a)
        return sorted(out, key=lambda a: a["requested_at"])

    def decide_approval(self, approval_id: str, decision: str, by: str, note: str = "",
                        edited_input: Optional[dict] = None) -> dict:
        if decision not in ("approved", "rejected", "edited"):
            raise RuntimeError_("decision must be approved, edited or rejected")
        with self.store.lock:
            name = f"approvals/{approval_id}.json"
            appr = self.store.read_json(name, None)
            if appr is None:
                raise RuntimeError_(f"no approval {approval_id}")
            if appr["decision"] != "pending":
                return appr  # deciding twice changes nothing
            if edited_input is not None:
                problem = self.validate(appr["action"], edited_input)
                if problem:
                    raise RuntimeError_(f"edited input is invalid: {problem}")
                appr["original_input"], appr["input"], decision = appr["input"], edited_input, "edited"
            appr.update({"decision": decision, "decided_by": by, "decided_at": iso(self.now())})
            if note:
                appr["note"] = note
            self.store.write_json(name, appr)
        self.log(f"{decision} {appr['action']} ({approval_id})", "done" if decision != "rejected" else "refused",
                 source="person", capability=appr.get("capability"), record_ref=appr.get("record_ref"),
                 detail={"approval": approval_id, "by": by, "note": note or None})
        return appr

    def run_due(self) -> list[Result]:
        """Carry out approved actions and deferred sends whose time has come. Call it every minute or so."""
        results = []
        for appr in self.approvals(pending_only=False):
            if appr["decision"] in ("approved", "edited") and not appr.get("executed_at"):
                results.append(self._execute_approved(appr))
        results.extend(self._run_scheduled_calls())
        return results

    def _execute_approved(self, appr: dict) -> Result:
        name, args = appr["action"], appr["input"]
        with self.store.lock:
            current = self.store.read_json(f"approvals/{appr['id']}.json", appr)
            if current.get("executed_at"):
                return Result("done", name, output=current.get("result"), approval_id=appr["id"], reason="already carried out")
            for contact in self.recipients(name, args):
                if self.is_suppressed(contact):
                    current.update({"executed_at": iso(self.now()), "result": "refused: opted out"})
                    self.store.write_json(f"approvals/{appr['id']}.json", current)
                    self.log(f"refused approved {name}: {contact} opted out since", "refused", detail={"approval": appr["id"]})
                    return Result("refused", name, reason=f"{contact} opted out after this was approved", approval_id=appr["id"])
            if name in QUIET_TOOLS and self.quiet_until():
                return Result("deferred", name, reason="approved, waiting for the end of quiet hours",
                              approval_id=appr["id"], retry_at=iso(self.quiet_until()))
            # Mark before running, so a crash cannot send it twice.
            current["executed_at"] = iso(self.now())
            self.store.write_json(f"approvals/{appr['id']}.json", current)
        res = self._run(name, args, current.get("capability"), current.get("record_ref"), source="person")
        res.approval_id = appr["id"]
        current["result"] = res.status if res.status != "done" else "done"
        self.store.write_json(f"approvals/{appr['id']}.json", current)
        return res

    # ---- the agent_* tools, provided by the runtime itself -------------------------

    def _builtin(self, name: str, args: dict, capability) -> Result:
        ref = args.get("record_ref")
        if name == "agent_log":
            e = self.log(args["event"], "done", detail=args.get("detail"), capability=capability, record_ref=ref, source="model")
            return Result("done", name, output={"logged": e["id"]})
        if name == "agent_request_approval":
            action = args["action"]
            if action not in self.tools or action in BUILTINS:
                return Result("refused", name, reason=f"{action} is not an action that can be approved")
            problem = self.validate(action, args.get("input") or {})
            if problem:
                return Result("refused", name, reason=f"the held input is invalid: {problem}")
            appr = self._hold(action, args["input"], args["why"], capability, ref, [])
            return Result("held", name, output={"approval_id": appr["id"]}, approval_id=appr["id"])
        if name == "agent_escalate":
            item = {"id": "esc_" + uuid.uuid4().hex[:12], "at": iso(self.now()), **args}
            self.log(f"escalated: {args['reason']}", "done", capability=capability, record_ref=ref, detail=item)
            self.store.append_line("escalations.jsonl", item)
            return Result("done", name, output={"escalation": item["id"]})
        if name == "agent_schedule":
            try:
                parse_iso(args["at"])
            except ValueError:
                return Result("refused", name, reason="'at' must be an ISO date-time")
            item = {"id": "task_" + uuid.uuid4().hex[:12], "kind": "task", "at": args["at"], "task": args["task"],
                    "record_ref": ref, "done": False}
            self.log(f"scheduled: {args['task']}", "done", capability=capability, record_ref=ref, detail={"at": args["at"]})
            self._add_scheduled(item)
            return Result("done", name, output={"task": item["id"]})
        if name == "agent_is_suppressed":
            return Result("done", name, output={"suppressed": self.is_suppressed(args["contact"])})
        if name == "agent_suppress":
            if self.level == "L0":
                return Result("refused", name, reason="internal tools are not allowed at L0 Watch")
            self.suppress(args["contact"], args["reason"])

class Guard:
    def __init__(self, checks: Path | str, mode: Optional[str] = None):
        self.checks = json.loads(Path(checks).read_text(encoding="utf-8")) if Path(checks).exists() else {}
        self.th = {"inbound": 0.7, "outbound": 0.5, **(self.checks.get("thresholds") or {})}
        mode = (mode or os.environ.get("BLVK_GUARD") or "auto").lower()

    def _laya(self, text: str, questions: dict) -> dict:

            return {}
        try:
            out = self.router.predict(text, questions)["answers"]
        except Exception:
            return {}
        probs = {}
        for name, a in out.items():
            if a.get("type") == "noul":
                probs[name] = float(a["noul"])
            elif a.get("type") == "choice":
                probs[name] = {"choice": a["choice"], "confidence": float(a.get("answer_confidence", 0))}
        return probs

        probs = self._laya(text, self.checks.get("inbound", {}))
        for key in ("injection", "opt_out", "wants_person", "upset"):

            if rules[key] or (isinstance(p, float) and p >= self.th["inbound"]):
                flags.append(key)
                reasons.append(f"{key} ({'rule' if rules[key] else f'laya {p:.2f}'})")
        return {"flags": flags, "reasons": reasons, "opt_out_explicit": explicit,

# Test scenarios

Walk through each scenario with real examples from your business before a capability goes live. The rules that apply to every capability are already automated: run `python -m unittest runtime/test_runtime.py -v`.

## Automated in runtime/test_runtime.py

- Reads run at every level; your own records change from Draft; anything reaching a customer, a supplier or money is held at Draft and refused at Watch.
- A held action runs exactly once after approval, never after rejection, and never if the contact opted out in the meantime.
- A contact who opted out is never contacted, at any level. A message that says STOP records the opt-out at once.
- Customer-facing sends at night wait for the morning instead of going out.
- A draft that names a price, discount, refund, date or time is held for a person even at L3 Operate.
- Instructions hidden in a customer's message are flagged and fenced off from the model.
- Every action is logged before it happens, and editing the log afterwards is detected.

## By capability

### 1. Booking

**Given** a customer asks to book.

**When** the agent runs the procedure in `prompts/capabilities/appt.book.md`.

**Then**

- At L1 Draft, `calendar_create_event`, `email_send`, `telephony_send_sms` are held with an approval record, and nothing reaches anyone until a person approves.
- When no slot fits in the next two weeks: `agent_escalate` is called and the agent does not carry on alone.
- When the request is outside what the business does: `agent_escalate` is called and the agent does not carry on alone.
- Pass: Offered slots never conflict, never breach buffer rules, and land on the right calendar.

### 2. SMS

**Given** a message arrives on SMS.

**When** the agent runs the procedure in `prompts/capabilities/chan.sms.md`.

**Then**

- At L1 Draft, `telephony_send_sms`, `telephony_call` are held with an approval record, and nothing reaches anyone until a person approves.
- When someone asks for a person: `agent_escalate` is called and the agent does not carry on alone.
- When a message looks like a complaint or an emergency: `agent_escalate` is called and the agent does not carry on alone.
- Pass: A round-trip text conversation completes, and opt-outs are honoured immediately and permanently.

### 3. Quote follow-up

**Given** a quote is sent to a customer.

**When** the agent runs the procedure in `prompts/capabilities/quote.followup.md`.

**Then**

- At L1 Draft, `email_send`, `telephony_send_sms` are held with an approval record, and nothing reaches anyone until a person approves.
- It stops when the quote is accepted or declined.
- It stops when the customer replies.
- A step that falls between 21:00 and 08:00 for the recipient waits and is not skipped.
- When the contact replies angrily, disputes something, or asks for a person: `agent_escalate` is called and the agent does not carry on alone.
- When a step fails to send twice: `agent_escalate` is called and the agent does not carry on alone.
- Pass: A quote is chased on the agreed schedule, stops instantly on any reply, and records the reason it was lost.

### 4. Interaction logging

**Given** a new contact or activity arrives.

**When** the agent runs the procedure in `prompts/capabilities/crm.logging.md`.

**Then**

- It only reads and keeps your own records, so nothing reaches anyone.
- When two records disagree and neither is clearly right: `agent_escalate` is called and the agent does not carry on alone.
- Pass: Every agent interaction appears on the correct record within a minute.

### 5. CRM read and write

**Given** a new contact or activity arrives.

**When** the agent runs the procedure in `prompts/capabilities/crm.sync.md`.

**Then**

- It only reads and keeps your own records, so nothing reaches anyone.
- When two records disagree and neither is clearly right: `agent_escalate` is called and the agent does not carry on alone.
- Pass: Records created and updated by the agent match the field mapping exactly, with no orphan records.
